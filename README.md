# Звездочёт — онлайн-школа для детей

Одна ссылка для всех тренажёров: aleksarulezzz.ru/zvezdochet/

- **Главная** — приветствие, «Мой день», уровень, план на сегодня, коллекция находок, мини-игра.
- **Предметы** — математика и китайский открываются внутри Звездочёта (это тренажёры из репозиториев `olympiad-math-trainer` и `chineese`), английский встроен сюда: 12 тем × 3 урока.
- **Карта ученика** — звёздная карта с тремя путями к планетам. Звёзды загораются за решённые задачи, выученные китайские слова и пройденные темы английского. Карту можно двигать и приближать, по звезде можно нажать.

Прогресс хранится только в браузере (localStorage). Тренажёры работают на том же домене, поэтому карта читает их прогресс напрямую: `ol5progress_*` (математика), `hanzi-hero-v1` (китайский), `zv-english-v1` и `zv-hub-v1` (Звездочёт).

Персональные данные не собираются: нет регистрации, имён и фото, ребёнок выбирает героя-эмодзи.

Публикация: GitHub Pages, ветка `main`, корень.
